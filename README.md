## Тема
Коллекция List в C#.
## Что реализовано
- ввод и вывод списка задач;
- добавление и вставка;
- удаление по значению и индексу;
- поиск первого совпадения;
- проверка допустимости индексов;
- обработка пустого списка.
## Короткие ответы
1. Чем List отличается от массива и как узнать количество элементов списка?
Ответ: List может изменять количество элементов.
Количество элементов списка определяется через Count.
2. Чем отличаются Remove() и RemoveAt()?
Ответ: Remove() удаляет элемент по значению.
RemoveAt() удаляет элемент по индексу.
3. Почему для вставки допустим индекс Count, а для удаления — нет?
Ответ: Потому что элемент можно добавить в конец списка.Для удаления нужен уже существующий индекс.
